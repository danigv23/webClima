##### WEB PARA CONSULTAR EL CLIMA DE DISTINTAS CIUDADES

## OBJETIVO
**MEJORAR MIS CONOCIMIENTOS DE JAVASCRIPT, MARIADB Y NODEJS,**
**ADEMAS DE APRENDER A CONSUMIR APIS Y UN POCO DE BACKEND CON**
**EXPRESS (USO DE METODOS HTTPS).**

## IDEA GENERAL

**PANTALLA INICIAL PARA CONSULTAR CUAL ES LA PRIMERA CIUDAD**
**PARA COMPROVAR TODOS LOS DATOS POSIBLES DEL CLIMA EN LA**
**ACTUALIDAD, ADEMAS DE PODER GUARDAR EN EL NAVEGADOR LAS**
**CIUDADES ANTERIORMENTE SELECCIONADAS**

## TECNOLOGIAS NECESARIAS
- JAVASCRIPT
- NODEJS
- MARIADB
- API CLIMA
- EXPRESSJS
